while loops, nested loops and exam preparation. One `.py` file per problem.

## Run

Needs Python 3.14. Every lecture has a `test_*.py` that runs each solution with sample input.

```bash
cd 005-Conditional-Statements-Advanced
python 002_cinema_ticket.py         # type the input, Enter
python -m unittest -v
```
